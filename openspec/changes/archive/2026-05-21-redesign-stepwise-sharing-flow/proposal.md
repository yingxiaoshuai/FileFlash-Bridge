## Why

当前首页把启动服务、共享文件和项目内容同时铺在一个页面里，新用户很难判断第一步应该先做什么；服务未启动时，后续共享与项目区域也容易显得空、散、重复。现在需要把首页改成真实可操作的分步骤工作流，而不是使用说明页：用户先启动服务，服务可用后再自然进入共享文件和项目内容管理，同时提升首页视觉质感。

## What Changes

- 将首页主流程从“所有能力同屏铺开”调整为“真实功能按步骤显露”的操作体验，而不是新增说明页或教程页。
- 服务未启动时，首页中心展示一个醒目的大圆形启动入口，作为首屏主操作；网络状态、访问模式和必要提示作为辅助信息保留。
- 服务启动成功后，再展开浏览器访问地址、二维码、共享文件区域和当前项目内容，形成“启动服务 → 共享文件 → 查看项目内容”的使用路径。
- 调整语言切换入口的显示方式：中文界面中只需要显示可切换到的 `English`，英文界面中显示可切换到的 `中文`，让真正想切换语言的用户更容易理解。
- 优化首页整体视觉层级、留白、表面质感、按钮样式和状态反馈，减少简陋感，继续沿用 React Native Paper 与现有主题 token。
- 保持现有局域网传输能力、文件共享列表、项目消息/文件管理、安全模式、复制链接、刷新地址和停止服务语义不变。
- 不引入新的第三方原生库或自定义 Native Module；本次变更优先在 React Native 共享 UI、状态编排和文案层完成。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `workspace-visual-refresh`: 调整首页视觉与信息架构，要求未启动状态以中心大圆形启动入口作为主操作，并在服务启动后再展开共享文件和项目内容。
- `local-transfer-server`: 调整服务控制在工作台中的呈现契约，明确服务启动是步骤式共享流程的第一步，但不改变本地传输服务接口或传输协议。
- `app-language-preferences`: 调整语言切换入口显示契约，当前语言界面只显示另一个目标语言，减少中文用户误触或困惑。

## Impact

- 影响共享代码：`src/app/screens/HomeScreen.tsx`、设置页/语言入口相关组件、`src/app/appShellStyles.ts`、`src/modules/localization/i18n.tsx`、工作台相关组件和测试。
- 影响体验：iOS 与 Android 首页首屏、服务启停状态、共享文件区可见时机、当前项目内容展示时机、语言切换入口显示和相关文案。
- 传输与权限：不改变文件上传、共享下载、文本提交、二维码访问、安全模式、后台保活和文件保存权限边界；仍需在双端验证启动服务、局域网访问、共享文件下载和项目内容展示没有退化。
- 依赖影响：不新增第三方原生依赖，不新增平台专属 Native Module。
